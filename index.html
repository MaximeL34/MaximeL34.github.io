    04 · Experience

    Where I've delivered

    2025 — Present · Healthcare

    AI Data Engineer — Ramsay Santé engagement

    Talan · Europe's leading private hospital group — parallel AI workstreams sponsored by the client's Data Office, over a ~2.2M inpatient-stays-per-year scope

    Billing-rejection platform on Azure (AKS)

    Designed and shipped the platform that flags invoices likely to be rejected by the national health insurer before they are sent: a hybrid scoring API (deterministic rules engine naming the rejection reason + XGBoost risk score with SHAP), an Azure SQL data model (14 tables), a dedicated data-access API (cursor pagination, one managed identity per use case — no database secret in the orchestrator), n8n-orchestrated daily analysis and a role-based review app for billing clerks. Deployed on AKS with Helm + Argo CD; runs daily on 3 pilot hospitals. A CronJob scores every prediction against the insurer's actual verdict, so precision is measured in production, not assumed.

    LLM evaluation on billing: drift, hybrid design, honest model choice

    Before the platform, owned the 81-invoice benchmark behind it: diagnosed a GPT model-version drift on Azure (80% → 59-72%), analysed false-positive patterns and drove adoption of the hybrid architecture I recommended — deterministic rules for structured rejection reasons, LLM for semantic ones. Built the 24-code rejection reference base and chose XGBoost over LLM fine-tuning for auditability, cost and reproducibility.

    AI-assisted medical coding: benchmark, then three audit agents

    Owned the multi-LLM ICD-10 coding pipeline end to end: GPT, Gemini, Mistral, Grok and Claude benchmarked with a weighted hierarchical scoring I designed, RAG (FAISS) and a React validation interface for medical coders — 92% accuracy on the primary diagnosis vs an 80% human baseline in the pilot. Then built three audit agents on top (DRG revaluation, record completeness, coding quality) under a strict evidence contract: a proposal that doesn't quote the patient record verbatim is rejected. 89% recall on missing pathology reports over 400 stays; 83% of labelled coding-quality targets detected. Containerised for AKS (web app, chat, scheduled pipeline) with state on Azure Blob Storage.

    Clinical document extraction

    Day-hospital eligibility: an LLM extracts strict JSON, with a verbatim quote for every value, from emergency and pre-anaesthesia records, then deterministic rules apply the clinical thresholds — the LLM reads, it doesn't decide. Validated on a pilot hospital's real corpus at a measured US$0.81 per 1,000 documents, with a follow-up app for nurse coordinators (event-sourced status, evidence view, monitoring). Same pattern reused for a France 2030 research programme: 22 regulatory variables extracted from 157 oncology stays, each with its cited source (feasibility study).

    Privacy pipeline for health data

    Owned the de-identification that runs before any LLM call: OCR, NER (EDS-Pseudo, from the Paris public hospitals) and a regex safety net for what the model misses, in a fault-tolerant pipeline — per-document timeouts, resumable runs, incremental sync to Azure with weekly-rotated delegation tokens. Only de-identified documents ever leave the client's server.

    Enterprise agents on the client's internal AI

    Built agents on the group's internal assistant (Open WebUI) for the Finance department: one compiles and summarises 81 monthly site reports, with every quoted figure automatically checked against its source; another consolidates 26 provision workbooks into a controlled national Excel, reconciled with the group consolidation system, plus a two-page briefing — personal names never reach the model. Also built documentation agents that draft use-case framing sheets and flag gaps instead of inventing.

    Architecture, platform strategy & data foundations

    Architected an automated public-funding watch validated with the client's Azure architect — AKS CronJob, PostgreSQL + pgvector (HNSW, 3072-dim embeddings) for semantic de-duplication, Bing Grounding, Key Vault CSI, Helm + Argo CD across 5 environments. Benchmarked Dataiku, Databricks and Azure AI Foundry for the group's AI platform under health-data hosting constraints. Drove the Master Data Management workstream and Power BI reporting, and built an Azure Document Intelligence tool that splits scanned billing batches into ~900 single invoices.
